# Darcy Construction — Client Handover Checklist

## Content and brand assets

- [ ] Approved leadership portraits.
- [ ] Approved leadership biographies.
- [ ] Darcy-owned project photography and reuse permissions.
- [ ] Final social-sharing image.
- [ ] Verified accreditations or memberships, if they should be published.
- [ ] Company registration number, if required in the footer.
- [ ] Additional approved testimonials for projects without published quotes.
- [ ] Approved Insights article bodies and authors.

## Production configuration

- [ ] Production domain confirmed.
- [ ] `RESEND_API_KEY` configured.
- [ ] `CONTACT_TO_EMAIL` configured.
- [ ] `CONTACT_FROM_EMAIL` configured and domain-verified.
- [ ] Analytics decision and consent configuration confirmed.
- [ ] Search Console verification completed.

## Final approval

- [ ] Content verified by Darcy.
- [ ] Photography permissions verified.
- [ ] Contact enquiry tested from production.
- [ ] Mobile and desktop QA signed off.
- [ ] Accessibility and Lighthouse checks completed after deployment.
- [ ] Production sitemap submitted.
- [ ] Rollback owner and launch date confirmed.

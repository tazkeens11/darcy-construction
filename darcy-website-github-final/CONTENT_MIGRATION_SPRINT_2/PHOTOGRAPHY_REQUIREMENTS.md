# Photography and Asset Requirements

## Existing public asset source

The current site contains a substantial homepage and case-study image library. The fact that an image is publicly displayed does not by itself prove Darcy ownership, model/client permission, unrestricted reuse or suitability for the new crop. Every image must be registered and approved before publication.

## Required register fields

For every proposed image record: source URL, local filename, project, subject, image type, photographer/owner, permission status, people consent, intended route, alt text, crop, focal point, dimensions, modern-format variant and replacement date.

## Rules

Do not publish stock photography as Darcy evidence. Do not use a project image for a person, testimonial or accreditation claim unless the relevant consent and context are recorded.

# Darcy Construction — Sprint 2 Content Migration Package

## Purpose

This package audits the public Darcy Construction website and defines how verified content should move into the approved new site. It is a review document, not a publishing instruction.

## Evidence rule

- **Verified** means publicly present on the current Darcy website at the time of this audit.
- **Approval-gated** means the source is public but the claim is time-sensitive, permission-sensitive, legally sensitive or not independently clear enough to publish without Darcy confirmation.
- **Missing** means the current site does not provide enough content to build the intended destination page.

No homepage, design-system, route or deployment files were changed for Sprint 2.

## Package contents

1. `CONTENT_MIGRATION_REGISTER.md` — source-page decisions and destinations.
2. `CASE_STUDY_INVENTORY.md` — project-by-project evidence and launch recommendations.
3. `SITE_MAP_AND_CONTENT_INVENTORY.md` — proposed final page architecture and content inventory.
4. `PHOTOGRAPHY_REQUIREMENTS.md` — missing photography and permissions register.
5. `CONTENT_GAPS_AND_IMPLEMENTATION_PLAN.md` — launch gaps, evidence placement and priorities.

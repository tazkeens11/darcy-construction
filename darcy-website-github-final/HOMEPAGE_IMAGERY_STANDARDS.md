# Darcy Homepage Imagery Standards v1.0

## Global rule

Show the quality before describing it. Photography leads; copy provides context.

## Image specifications

| Placement | Orientation | Aspect ratio | Minimum source | Preferred composition | Text overlay |
|---|---|---|---|---|---|
| Hero | Landscape | 16:9 or wider | 2400px wide | One confident completed building with clear architectural silhouette and calm negative space | No; copy sits in a separate readable content area |
| Who We Are | Landscape | 4:3 | 1600px wide | Site team, client conversation or strong construction detail | No |
| Featured Project | Landscape | 16:10 | 2200px wide | Hero exterior or completed building in use | No |
| Selected Project 1 | Landscape | 4:3 | 1600px wide | Exterior or interior with clear project identity | No |
| Selected Project 2 | Landscape | 4:3 | 1600px wide | Detail, material or people-in-use image | No |
| Closing CTA | Landscape | 16:9 | 2000px wide | A resolved project view with room for a calm CTA block | No; CTA sits in a separate band |

## Delivery rules

- Darcy-owned or permissioned photography only.
- Bright, authentic, architectural and professionally captured.
- No stock construction imagery.
- Preserve focal point when cropping responsive variants.
- Provide width, height, alt text, source and permission status for every image.
- Generate responsive WebP/AVIF variants where licensing and pipeline allow.
- Lazy-load all images except the true hero LCP image.

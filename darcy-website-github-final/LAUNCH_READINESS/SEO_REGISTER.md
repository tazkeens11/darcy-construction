## Final SEO checks

- One H1 per route; no skipped heading levels.
- Titles and descriptions unique, factual and approved.
- Canonicals match the Production URL Strategy.
- Sitemap contains only launch-approved URLs and no hash routes.
- Robots permits production crawling and excludes staging.
- Schema matches visible content; omit approval-gated fields.
- Every image has factual alt text and an approved source.
- Internal links resolve without generic or dead project routes.
